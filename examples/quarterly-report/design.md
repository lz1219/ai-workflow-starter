# 季度月报设计

财务需要月度明细和可比较的季度均值。一季度内固定输出一、二、三月，月份顺序与输入顺序无关。下游模板在“月报”上读取金额列，用 SUM 和 AVERAGE 汇总三个单元格。

| 编号 | 场景 | 双方确认的预期 |
| --- | --- | --- |
| AC-1 | 一月上报 120，二月缺报，三月实报 0 | 金额依次为 120、0、0。合计 120，季度平均 40。 |
| AC-2 | 整季都没有上报 | 三行均为数值 0，合计和平均均为 0。 |
| AC-3 | 领导版，同 AC-1 的输入 | 一、三月标为“已上报”，二月标为“未上报”。三个月的平均仍是 40。 |
| AC-4 | 用原有两个参数导出财务版 | 保留原表结构、数值格式和公式。整季未报时，领导版三行都标为“未上报”。 |

**决定依据**　2026-11-18，维护者在季度导出演练中选择“缺月填数值 0，也参与平均”。这使每个季度都按三个日历月计算。源记录仍区分缺报和实报零，财务金额列允许两者呈现相同数值。此口径适用于本示例的一季度报表；输入含季外月份时沿用历史导出路径。

**第二轮决定**　2026-11-19，维护者确认“领导想看出哪些月没报，季度平均沿用财务口径”。从这一版起，领导版在 C 列显示填报状态，依据源记录中是否存在该月份。二月与三月的金额相同，只看金额无法恢复这个信息。财务模板继续从 B 列取数。调用方可通过关键字参数 `show_reporting_status=True` 选择领导版；季外输入仍走原路径。此变更追加 AC-3 和 AC-4，AC-1 和 AC-2 继续生效。
