## 明确不覆盖

以下内容没有随 Skill 分发的专门参考，按项目实际入口探查，或请维护者提供资料：

- 数据库迁移、回滚与数据回填；
- 云平台、容器编排、基础设施即代码；
- 认证、授权、租户隔离与安全合规；
- 数据/ML 流水线、模型评估与数据质量；
- 移动端、桌面端和嵌入式；
- monorepo 工具链、跨仓库版本协同。

## 补充一个技术栈

1. 复制 [_template.md](_template.md) 为 `<技术栈>.md`。
2. 按模板填写适用边界、探查顺序、入口与命令、约定、陷阱、验证和待确认项。
3. 每条约定附可核对证据：文件路径、命令、测试或维护者确认。
4. 在本表增加一行，写明覆盖内容和不覆盖的部分。
5. 用至少一个真实项目走一遍该参考；只验证文档格式不算验证参考有效。
6. 在 PR 中记录验证范围、未覆盖环境和仍待确认的问题。

参考应帮助接手者回答三个问题：到哪改、按什么约定改、怎么证明改对了。
无法回答时，补证据或标为待确认，不要补猜测。
